Care in Action — project file map
================================

For user instructions and a quick start, see README.md.
For architecture, workflows, calculations, validation, data catalogs, and exports,
see PROJECT_REFERENCE.md.

Repository files
----------------
index.html
  HTML shell, shared header/footer, stylesheet link, and ordered script loading.

assets/
  cie-logo.png — application mark used in the header and favicon.

css/
  styles.css — design tokens, layout, responsive styles, components, and print/
  motion accessibility rules.

js/
  app.js — application state, step routing, validation gates, and boot.
  calculator.js — pure impact calculation and summary shaping.
  content.js — UI copy, validation messages, labels, and report text.
  data.js — volunteer roles, clinical services, benchmark rates, and references.
  utils.js — formatting, validation, and small DOM helpers.
  components/
    EntryList.js — reusable searchable add/remove input rows.
    NavigationButtons.js — shared Back/Next button row.
    ProgressIndicator.js — five-step progress navigation.
  services/
    exportService.js — browser print/PDF and XLSX workbook generation.
  views/
    WelcomeView.js — introduction and privacy scope.
    ClinicInformationView.js — clinic identity, reporting period, and optional cost.
    ImpactMethodView.js — volunteer-hours or clinical-services selection.
    ImpactActivityView.js — method-specific aggregate activity entry.
    ImpactSummaryView.js — computed results, methodology, references, and exports.

No build configuration or package manifest is present. See README.md for running
the application locally.
