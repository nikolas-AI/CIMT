Care in Action — project file map
================================

For quick start instructions, see README.md.
For architecture and calculation details, see PROJECT_REFERENCE.md.
For end-user instructions, see USER_GUIDE.md.

Repository root
---------------
.gitignore
  Repository ignore rules for local environment files, editor artifacts, and
  non-source files that should not be committed.

.vscode/
  Workspace settings and editor configuration for local development.

README.md
  Project overview, purpose, local run instructions, source notes, licensing
  caveats, and usage guidance.

PROJECT_REFERENCE.md
  Technical reference covering architecture, state flow, validation rules,
  calculation logic, and export behavior.

USER_GUIDE.md
  Step-by-step instructions for completing an impact report and interpreting
  the estimate.

Care_in_Action_User_Guide.pdf
  Exported PDF version of the user guide for distribution or offline use.

index.html
  Browser application shell, shared header/footer, CSS link, and ordered script
  loading for the app.

plans4nxt.txt
  Working notes and future enhancement ideas for continued project iteration.

assets/
  cie-logo.png — primary app branding/logo.
  TXACC-logo.png — Texas Association of Charitable Clinics branding.
  thrc-logo.png — Translational Health Research Center branding.

css/
  styles.css — design tokens, layout, accessibility styling, responsive rules,
  and print-ready presentation.

js/
  app.js — in-memory state, wizard navigation, validation logic, and startup.
  calculator.js — pure impact calculation engine and result shaping.
  content.js — UI labels, validation messages, report copy, and source text.
  data.js — embedded benchmark rates, service catalogs, and metadata.
  utils.js — formatting helpers, validation rules, DOM utilities, and shared
  support functions.

  components/
    CompositionPieChart.js — reusable chart component for quantity-share views.
    EntryList.js — row-based form builder for repeated activity entries.
    NavigationButtons.js — shared Back/Next actions across the workflow.
    ProgressIndicator.js — five-step progress indicator UI.

  services/
    exportService.js — PDF and Excel export logic.

  views/
    WelcomeView.js — intro and onboarding screen.
    ClinicInformationView.js — clinic metadata, dates, and cost input form.
    ImpactMethodView.js — method selection between volunteer and service-based
      reporting.
    ImpactActivityView.js — aggregate totals entry form and validation rules.
    ImpactSummaryView.js — estimate display, references, optional cost comparison,
      suggested impact statement, and export actions.

Project notes
-------------
- No build configuration or package manifest is present.
- The app runs directly in the browser; either open index.html in a browser or
  run "python3 -m http.server 8000" from the project root.
- The project uses embedded data and browser-based export features rather than a
  server-side application or build pipeline.
