    HOW THE APP WORKS
    -----------------
    This is a small browser app made with HTML, CSS, and JavaScript. It has no
    build step or framework. Open index.html in a browser to run it.

    The user moves through five screens:
    1. Welcome: learn what the tool does and what information you need.
    2. Clinic information: enter clinic details and the cost for the period.
    3. Calculation option: choose Volunteer Hours or Clinical Services.
    4. Activity: enter the information for your chosen option.
    5. Impact summary: review and download the results.

    FILE RESPONSIBILITIES
    ---------------------
    - data.js holds service names, rates, volunteer roles, and source links.
    - app.js holds the current answers and decides which screen is visible.
    - views/ creates each screen and connects its form fields to the answers.
    - components/ contains shared controls used by more than one screen.
    - calculator.js does the math and does not create or change HTML.
    - exportService.js creates the printable report and Excel workbook.
    - utils.js contains small helpers used by several files.
    - styles.css controls the appearance of every screen.

    TYPICAL DATA FLOW
    -----------------
    1. A view creates a form field, such as an input or dropdown.
    2. The user changes it, and the view saves the answer in app.js.
    3. When the user continues, the view checks the answer before moving on.
    4. calculator.js reads the saved answers and returns the results.
    5. The summary view displays those results; it does not do the math.

    When adding a service or reference, start in data.js. When adding a screen, add
    its rendering code in views/ and connect it to the step switch in app.js. Keep
    calculations in calculator.js and avoid putting business rules in markup.
