Care in Action — project file map
================================

For quick start instructions, see README.md.
For architecture and calculation details, see PROJECT_REFERENCE.md.

Repository root
---------------
.gitignore
  Repository ignore rules for local environment files and editor artifacts.

.vscode/
  Local workspace settings and editor configuration.

README.md
  Project overview, local run instructions, data sources, limitations, and usage.

PROJECT_REFERENCE.md
  Technical reference covering architecture, state flow, validation, calculations,
  data sources, and exports.

Care_in_Action_Polished_Guide.pdf
  PDF guide document.

index.html
  Browser application shell, shared header/footer, stylesheet, and ordered script
  loading.

plans4nxt.txt
  Working notes and future enhancement ideas.

assets/
  cie-logo.png — primary application branding.
  TXACC-logo.png — Texas Association of Charitable Clinics branding.
  thrc-logo.png — Translational Health Research Center branding.

batch/
  batch.css — styling for the activity import interface.

css/
  styles.css — design tokens, layout, accessibility, responsive rules, and
  summary-screen styling.

js/
  app.js — in-memory state, wizard navigation, validation, and startup.
  calculator.js — pure impact calculation and result shaping.
  content.js — UI labels, validation messages, and report text.
  data.js — embedded benchmark rates, service catalogs, and source metadata.
  utils.js — formatting, validation, and DOM helpers.

  components/
    CompositionPieChart.js — reusable quantity-share charts for the summary and
      printable report.
    EntryList.js — reusable row-based activity entry form.
    NavigationButtons.js — shared Back/Next navigation controls.
    ProgressIndicator.js — five-step progress indicator.

  services/
    batchImportService.js — file templates, parsing, and activity-row validation.
    exportService.js — browser print/PDF and Excel workbook exports.

  views/
    WelcomeView.js — welcome and onboarding screen.
    ClinicInformationView.js — clinic details, reporting dates, and optional cost.
    ImpactMethodView.js — calculation-method selection.
    ImpactActivityView.js — activity entry and import interface.
    ImpactSummaryView.js — estimate, breakdowns, methodology, references, and
      PDF/Excel download actions.

tests/
  batch-import.test.js — batch-import parsing and validation tests.
  composition-pie-chart.test.js — quantity-share chart tests.
  export-service.test.js — PDF and Excel export tests.

Project notes
-------------
- There is no build configuration or package manifest.
- Run locally with "python3 -m http.server 8000" from the project root and open
  http://localhost:8000.
- The app uses embedded data and browser-based exports; it has no server-side
  application or build pipeline.
